# Claude 托管代理：让你将产品落地速度提升 10 倍

> Claude Managed Agents

## 0 前言

今天，我们推出了 Claude 托管代理（Managed Agents），这是一套可组合的 API，用于大规模构建和部署运行在云端的智能代理。

在此之前，开发代理通常需要投入大量时间搭建安全基础设施、管理状态、配置权限，以及在每次模型升级时重写代理逻辑。托管代理将高性能的代理执行框架与生产级基础设施结合，让你可以在几天内完成从原型到上线，而不是耗费数月。

无论你是在构建单一任务的执行器，还是复杂的多代理流水线，都可以把精力放在用户体验上，而不是运维成本上。

Claude 托管代理现已在 Claude 平台开启公测。

## 1 构建和部署代理，速度提升 10 倍

要将一个代理投入生产环境，通常需要具备沙箱化代码执行、检查点机制、凭证管理、权限控制，以及端到端的追踪能力。在真正交付给用户之前，这些基础设施往往就要花上几个月时间。

托管代理帮你处理这些复杂问题。你只需要定义代理的任务、工具和约束规则，其余由我们在基础设施上运行。内置的编排系统会自动决定何时调用工具、如何管理上下文，以及在出错时如何恢复。

托管代理包含以下能力：

- **生产级代理能力**：提供安全沙箱、认证机制以及工具调用执行，无需你自行搭建。
- **长时间运行会话**：代理可以连续自主运行数小时，即使断开连接，进度和结果也会被保留。
- **多代理协作**：代理可以启动并调度其他代理，将复杂任务并行拆解处理（目前为*研究预览*，可[在此申请](http://claude.com/form/claude-managed-agents)）。
- **可信治理机制**：通过细粒度权限、身份管理和执行追踪，让代理可以安全访问真实系统。

## 2 为充分发挥 Claude 能力而设计

Claude 模型天生适合用于构建智能代理。托管代理专为 Claude 打造，让你以更少的投入获得更好的效果。

使用托管代理时，你只需定义目标和成功标准，Claude 会自动进行自我评估并反复优化，直到达成目标。同时，它也支持传统的提示-响应模式，方便你在需要时进行更精细的控制。

在内部针对结构化文件生成的测试中，与标准提示循环相比，托管代理的任务成功率最高提升了 10 个百分点，且在复杂问题上的提升最为明显。

Claude 控制台内置了会话追踪、集成分析和问题排查工具，你可以查看每一次工具调用、决策过程以及失败原因。

## 3 团队正在构建的应用

各类团队已经在生产环境中使用托管代理，实现了 10 倍的开发提速。如：

- 读取代码库、规划修复并自动提交 PR 的编程代理
- 可加入项目、接手任务并与团队协作交付成果的效率代理
- 用于处理文档、提取关键信息的金融和法律代理。将上线周期缩短到几天，意味着可以更快为用户创造价值

- [**Notion**](https://claude.com/customers/notion-qa)：让团队可以在工作空间内直接把任务交给 Claude（目前在 Notion Custom Agents 中为私有 Alpha）。工程师用它编写代码，知识工作者用它制作网站和演示文稿。数十个任务可以并行执行，同时团队共同协作完成成果。
- [**Rakuten**](https://claude.com/customers/rakuten-qa)：在产品、销售、市场和财务等多个部门部署企业级代理，并接入 Slack 和 Teams，使员工可以直接分配任务并获得表格、幻灯片或应用等交付成果。每个专业代理都能在一周内完成部署。
- [**Asana**](https://claude.com/customers/asana-qa)：打造了 AI Teammates（AI 队友），在 Asana 项目中与人类协作，承担任务并起草成果。借助托管代理，团队能够以远超以往的速度添加高级功能。
- [**Vibecode**](https://claude.com/customers/vibecode)：以托管代理作为默认集成方案，帮助用户从提示快速生成并部署应用，推动新一代 AI 原生应用的发展。用户现在可以将相关基础设施的搭建速度提升至少 10 倍。
- [**Sentry**](https://claude.com/customers/sentry)：将其调试代理 Seer 与基于 Claude 的代理结合，后者负责编写补丁并提交 PR，使开发者可以在一个流程中从发现问题到获得可审查的修复方案。该集成在托管代理上仅用数周就完成，而不是数月。

## 4 入门指南

托管代理采用按使用量计费。除标准 Claude 平台的 token 费用外，活跃运行时间还需支付每会话每小时 0.08 美元。

Claude 托管代理现已在 Claude 平台上线。前往 [Claude 控制台](https://platform.claude.com/workspaces/default/agent-quickstart)，或使用全新的 CLI 部署你的第一个代理。

开发者还可通过最新版 Claude Code 和内置的 claude-api Skill 使用托管代理。只需输入 “start onboarding for managed agents in Claude API” 即可开始。
